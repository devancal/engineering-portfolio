InternAI — Internship Application Workspace

An experimental personal tool I’m developing to organize my internship search and explore résumé-based job matching, application tracking, and workflow automation.

CONTEXT
Personal experiment · AI-assisted development
TOOLS
JavaScript · Vercel · PDF.js · AI coding tools
FOCUS
Application organization & workflow

What I’m exploring

The project started as an internship-discovery application and has grown into a place for me to experiment with organizing applications, storing job information, résumé-based matching, status tracking, and application workflows.

It is not a polished public product. Some features are incomplete or unreliable, and I may ultimately keep it as a personal application-management tool rather than release it publicly.

My role & process

  • AI-assisted implementation: Much of the code is generated or implemented with AI coding tools rather than written by me from scratch.
  • Product direction: I define the features, workflows, behavior, and changes I want the application to have.
  • Testing & debugging: I test builds, identify broken behavior, describe issues, review changes, and iterate on fixes.
  • Learning: The project is a way for me to learn how a larger web application fits together while building something useful for my own internship search.

CURRENT STATUS

InternAI is experimental and actively changing. It currently has features that do not work consistently, so this portfolio does not present it as a finished product or claim that I authored the full codebase myself. The value of the project is in the product decisions, testing, debugging, iteration, and AI-assisted development process.
